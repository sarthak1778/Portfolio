How It Syncs to Vercel
  • When you click sync, the endpoint uses your GITHUB_TOKEN.
  • It commits the update directly into data/linkedin-activity.json in your repository.
  • Vercel detects the commit and redeploys your portfolio in ~30s.
  • No database or third-party server needed.
Hands-Off Automation via Zapier or Make.com

Set up a free scenario on Make.com or Zapier with the trigger: "LinkedIn: New Post by Me" and the action: "HTTP POST".

1. Webhook Endpoint 

POST https://sarthak-choudhary.vercel.app/api/sync-linkedin

2. HTTP Headers 

Content-Type: application/json
x-sync-secret: sarthak-portfolio-sync-key

3. Sample JSON Body 

{
  "title": "{{Post Title or First Line}}",
  "description": "{{Post Content}}",
  "url": "{{Post URL}}",
  "type": "post",
  "technologies": ["Engineering", "Leadership"],
  "engagement": {
    "reactions": {{Reactions Count}},
    "comments": {{Comments Count}}
  }
}

4. Test with cURL in Terminal 

curl -X POST "http://localhost:3000/api/sync-linkedin" \
  -H "Content-Type: application/json" \
  -H "x-sync-secret: sarthak-portfolio-sync-key" \
  -d '{"title":"Test Sync via Webhook","description":"Verifying live sync automation","url":"https://linkedin.com"}'
